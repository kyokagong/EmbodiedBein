## 6. 仍存在的诚实缺口（下一步）

按会挡住设计验收排序：

1. **BHL HEAD `play.py` CLI**：没有 `--metrics_output` / `--export_only` / `--seed`。平台只快照已提交树。要现场 `eval.sim`，需要上游提交这些 flag，或平台继续只用已有 eval json。
2. **RLinf 完整 SFT/RLFT 冒烟**：镜像在，本轮没跑数小时训练。
3. **`data.retarget`**：tools 镜像缺 pinocchio，只能诚实失败。
4. **全量 ego 扫描**：44G 哈希很久；pipeline 失败状态应保留，不要改成假成功。
5. **残留 Isaac Streaming 容器**：更早的 `runheadless.sh` 可能仍占 GPU0；新 Job 走空闲卡。取消请用 `POST /jobs/{id}/cancel`（会调 ebd），不要只改 DB。
6. **Showcase / 视频墙 / 完整 3D 网格**：无资产时不造假模型。

硬约束未改：四个契约维数、外部仓只读、仅 ebd 持有 `docker.sock`、Redis **6380**、禁止给平台 Agent 开 shell / 改契约 / 真机放行。

## 7. 怎么演示

```bash
# 已 up 时
curl -fsS http://127.0.0.1:8000/healthz
curl --unix-socket /run/eb/ebd.sock http://ebd/v1/doctor   # gpus.length == 4

make smoke-job   # biped 短训；或 UI /train/submit
# 成功后：/train/runs/<run_id> 看 TSDB 曲线
# export：POST export.policy，inputs.resume_from=<train run_id>
```

默认 biped 冒烟：`num_envs=64`，`max_iterations=5`。Isaac 启动通常还要数分钟；失败只修 EGL/shm/只读/EULA/路径/PYTHONPATH，**禁止再加 stub**。
