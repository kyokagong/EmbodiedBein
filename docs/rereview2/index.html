需要重新审视的三件事

“RLinf 已注册”不是“每个模型都可以 SFT 或上机器人”

本地发现26个 builder 注册调用，其中包含价值模型与生成模型；当前 VLA SFT worker 有六类分支，入口仍有 BHL 特例。每项 load/SFT/RL/eval/export/target 能力独立绑定运行证据。

“成功数据集”不能代替“全部采集记录”

LeIsaac 直接 LeRobot recorder 的成功筛选会损失失败信息；转换还会裁剪前几帧。设计采用原始全尝试存档、筛选视图和转换审计，并保留 episode 祖先避免 Mimic 训练测试泄漏。

“量化更小”不是“Orin 上更快、更安全”

实际 Orin 产物必须验证 sensor-to-action 时延、任务表现与内存/热稳定。目标 engine 通过仿真测试端点参与闭环；没有目标证据时保留未验证状态。平台不进入真机实时控制回路。

本轮保持真机放行拒绝与 Agent 禁止集。交付阶段提供包、验证说明和现场证据登记；现场端侧独立执行。G1 当前仅仿真。

从基础可信到端到端验收

阶段共同完成条件
A / 基础可信表单输入、执行挂载、Run输出与血缘一致，重启可恢复
