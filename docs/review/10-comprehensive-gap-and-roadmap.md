## 2. 结构债与风险登记册

| 编号 | 类别 | 现象 / 债务描述 | 潜在风险 | 消除建议 |
|---|---|---|---|---|
| **R-01** | 控制面代码 | `backend/eb/api/routes.py` (825 行) 集中了全部路由 | 多人协作冲突，模块边界模糊 | 按资源拆分为 `jobs.py`, `models.py`, `datasets.py`, `evals.py`, `system.py` 等独立路由 |
| **R-02** | 依赖与通信 | Redis 6380 已部署但在控制面几乎处于闲置状态 | 失去事件流解耦优势，FastAPI 依赖轮询 | 将 ebd 事件与指标泵写入 Redis Streams，FastAPI 异步消费 |
| **R-03** | 存储架构 | MinIO 部署在 Compose 中，但产物默认走本地 CAS 目录 | 分布式扩展受限 | 保持本地 CAS 作为单机热层（符合单机轻量），MinIO 作为备份归档冷层 |
| **R-04** | 评估闭环 | 上游 BHL HEAD `play.py` 缺乏 CLI 选项 (`--metrics_output`, `--seed`) | 现场评估无法自动化执行 | 在适配器层提供轻量包装脚本，模拟输出标准 JSON 指标流 |
| **R-05** | 数据链路 | 44GB 全量哈希扫描在单一请求中易触发超时 | 阻塞控制面，流水线被判 `failed` | 将全量扫描改造为后台异步 Job，采用增量 `(path, size, mtime)` 比对 |
| **R-06** | 构建性能 | `api.Dockerfile` 中重复编译 Rust `ebctl` | 拉长 `make up` 构建时间 | 将 `ebctl` 仅保留在 `ebd` 镜像中，或利用多阶段构建缓存 |

### 3.1 阶段 P0 — 基础闭环与生产体验提升（约 1~2 周）
- **目标**：消除当前交互卡点，将 Showcase 与 Run 详情页提升至设计验收标准。
- **具体任务**：
  1. **[P0.1] Showcase 高保真重构**：对照 09.4 原型重构 `Showcase.vue`，实现现状概览、4 KPI 环、按月能力演进曲线与垂直里程碑时间轴。
  2. **[P0.2] Run 详情页图表与命令预览**：在 `RunDetail.vue` 中增加「复制等价命令」按钮，重构 ECharts 支持多图表网格分类。
  3. **[P0.3] 调度器超时强杀**：在调度循环中增加 `timeout_h` 检查，超时自动触发 `ebd.cancel_run` 并将状态更新为 `failed (timeout)`。
  4. **[P0.4] 任务提交支持多 JobKind**：在 `Submit.vue` 中支持 `train.rl`, `train.sft`, `eval.sim`, `export.policy` 的参数表单切换与预检。

### 3.2 阶段 P1 — 评估体系与跨域门禁闭环（约 2 周）
- **目标**：落地五层指标体系中的 L2/L3 核心诊断工具。
- **具体任务**：
  1. **[P1.1] Wilson 95% 置信区间**：在评估模块中引入二项分布置信区间计算，在报告与排行榜中强制标注样本量与置信区间。
  2. **[P1.2] L3 跨域观测漂移热力图**：实现 `Isaac vs MuJoCo vs Real` 的标准化观测差异 `|Δμ|/σ` 计算与热力图呈现。
  3. **[P1.3] 差异显著性判定**：在 `RunCompare.vue` 与 `EvalCompare.vue` 中完善多任务对比与显著性差异结论标注。

### 3.3 阶段 P2 — 数据主线与多栈支持（约 2~3 周）
- **目标**：建立数据六层模型实体，打通脚本专家自动采集流水线。
- **具体任务**：
  1. **[P2.1] 专家采集流水线 (`data.collect`)**：提供在 IsaacLab 中自动运行专家策略并导出 LeRobot v2 数据集的完整 Job 流程。
  2. **[P2.2] 漏斗审计下钻**：在 `Funnel.vue` 中增加阶段样本下钻抽屉与敏感性滑块模拟。
  3. **[P2.3] RLinf 长周期冒烟压测**：在 4×4090 宿主上完成多卡 SFT 真实训练验证。

### 3.4 阶段 P3 — 策略包数值自检与端侧遥测（约 2 周）
- **目标**：打通策略包导出数值一致性门禁与端侧遥测归档。
- **具体任务**：
  1. **[P3.1] 导出数值一致性自检**：在 `eb/bundle/pack.py` 中引入 ONNX vs PyTorch 绝对误差比对 (≤ 1e-4)，超标拒绝签名。
  2. **[P3.2] 分级放行界面**：在 `Bundles.vue` 中实现带有物理确认提示的 S0/S1/S2 放行操作流。
  3. **[P3.3] 遥测时序看板**：在 `RobotDetail.vue` 中展示控制环 Jitter p99 曲线与电机温度监控。

### 3.5 阶段 P4 — Agent ToolBus 完善与磁带回放（约 2 周）
- **目标**：将 Agent 升级为具备算力账本硬顶与磁带回归测试的值班助手。
- **具体任务**：
  1. **[P4.1] ToolBus 算力硬顶**：实现周 GPU·h 消耗累加与超额拦截。
  2. **[P4.2] 7 个核心剧本真实编排**：使日报生成、失败诊断、资源巡检通过 ToolBus 提取真实系统指标。
  3. **[P4.3] 场景磁带回归夹具**：在 `tests/agent/` 中构建磁带录制与离线断言框架 (`llm_calls == 0`)。

### 3.6 阶段 P5 — 工程架构解耦与 CI 门禁（全程穿插）
- **具体任务**：
  1. **[P5.1] 路由文件拆分**：将 `backend/eb/api/routes.py` 按资源拆分为独立子模块。
  2. **[P5.2] CI 四项最小门禁**：配置 Ruff 代码风格、适配器命令行快照测试、Domain 纯逻辑单测、Alembic 迁移回滚测试。
  3. **[P5.3] 设置中心完善**：补齐 `Settings.vue` 的五大子页面（配额、镜像矩阵、扫描配置、通知、系统参数）。
