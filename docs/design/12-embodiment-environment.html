12 · Embodiment Environment

本体与本体环境：
管资产、定义和怎么跑起来。

「契约」只锁住了 obs / act / Hz，名称不像在管机器人。 本章把它替换为两层实体：本体管品牌、来源与 3D 资产； 本体环境管一种可跑接口（关节、观测、动作、控制律）。 任务独立。训练时选定环境、任务、栈和镜像。 Berkeley-Humanoid-Lite 只被纳管，不迁仓、不改文件。

真源 本章 + 12.md 旧名 ec_* → ee_* 别名 训练 环境 × 任务 × 栈 × 镜像
完整条文在 Markdown 表格、schema、失败归因、十轮反思见 12-embodiment-environment.md。 本页是设计书里的导航章：结构、画面和与 02/09/11 的衔接。 旧词 Embodiment Contract / contract_id 仅为兼容；冲突时改代码，不改回本章。

12.1 换名解决什么

旧机制的价值留下：维度错误要在提交阶段拦住。 换掉的是范围——平台还要能接入新本体、看见 3D、草稿里改 YAML、 把同一套身体交给 Isaac 或 RLinf。这些不是一份只读契约卡片能表达的。

已拍板内容
两层本体 emb_* + 本体环境 ee_*。Job / 模型 / 数据集只引用已发布环境
任务独立Velocity / Reach / LIBERO 是 tsk_*，不是环境的一部分
草稿冻结草稿可改；发布后该版本不可变；改数字克隆 _v2
BHLgit_external 纳管 /data/kk/Berkeley-Humanoid-Lite，平台零写入
RLinf不造 Hydra yaml；入口来自 Task 绑定；双 code_refs 冻结

12.2 三实体

RLinf 的 env 不是本体环境 examples/embodiment/config/env/isaaclab_berkeley_reach.yaml 的 init_params.id 是 Gym 任务名。登记在 Task.stack_bindings.rlinf。 API 禁止用 env_id 指本体环境，一律 embodiment_env_id。

12.3 BHL：纳管不是迁移

外部仓只读原则（01.1）不变。 平台在 PG 里登记指针与接口快照；执行逻辑留在 source/berkeley_humanoid_lite/，资产留在子模块。 不插入 eb.embodiment.yaml，不把四份 YAML 写回 BHL。

平台侧（可 CRUD）

  • 本体记录与来源 git_external.path
  • 四份 ee_* YAML（现 contracts/ 改挂）
  • Task 绑定到已有 gym.register
  • worktree 缓存 /var/lib/eb/repos/bhl/<commit>
  • 3D：按相对路径 读 STL/URDF

仓侧（零写入）

  • /data/kk/Berkeley-Humanoid-Lite
  • Isaac 任务与奖励代码
  • URDF / MJCF / USD / meshes
  • lowlevel C++
  • tasks/manipulation/contracts.py 仍是 Python 常量
脏工作树禁止开训 直接 bind 活目录会让 play.py 写回 BHL。G1：只用干净 commit 的平台缓存。 跑完 git -C /data/kk/Berkeley-Humanoid-Lite status 必须干净。

来源写在本体上。能力徽章 preview / train / eval / deploy 必须诚实：没有 Task 栈绑定就不要点亮 train。

12.6 四元组交给 RLinf

可提交 Job = 已发布环境 × 兼容任务 × 栈 rlinf × 镜像 digest。 Adapter 不生成 RLinf 的 env yaml。与现成 compose.berkeley-openpi.yaml 同构：BHL 挂到 /workspace/berkeley， RLinf 在 /workspace/rlinf 或镜像内，差别是 commit 冻结、可写目录不落回两仓、Ray 端口 6390。 

spec:
  kind: train.rlft
  embodiment_env_id: ee_bhl_wbc_22dof_v1
  task_id: tsk_bhl_wbc_tracking
  stack: rlinf
  image: eb/rlinf:0.4.0-emb@sha256:…
  code_refs:
    embodiment: { kind: git_external, path: /data/kk/Berkeley-Humanoid-Lite, commit: 6ff398f }
    stack:      { kind: git_external, path: /data/kk/RLinf, commit: "…" }
  runtime: { ray: { port: 6390 } }

config_name 默认来自 Task（WBC → berkeley_wbc_ppo_mlp，其 defaults 已 include env/isaaclab_berkeley_wbc）。PYTHONPATH 含 BHL 三个 source 包，禁止对只读仓 pip install -e。overrides[] 不得改 obs/act/关节顺序。

Adapter 三条禁止 不把平台 YAML 覆盖进 RLinf 仓；不写 /data/kk/*；Ray 不准走 6379 / 平台 Redis 6380。 运行时维度对不上 → Run 失败，发 ee_*_v2 或改上游，不在 Adapter 里改数字。

12.7 门禁与 Agent

G1–G5 语义不变，主语改成本体环境。G1 额外查：环境已发布、任务兼容、栈绑定存在、镜像能力矩阵、 双 commit、数据集/基座同 ee_*、overrides 不改接口。

Agent 永久禁止：发布/改 active 环境、门禁豁免、真机放行。 允许只读扫描与（若开放工具）克隆草稿。详见 08 补丁段。
