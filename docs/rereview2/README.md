# EmbodiedBein 第二轮再审：多机器人数据与学习闭环

设计日期：2026-09-08。状态：**待评审的增量设计，不代表功能已经实现**。

目标是让同一个平台管理 **SO101 单臂、G1 EDU 仿真、Berkeley Humanoid**，完成数据生产、训练、评估、面向 Jetson AGX Orin 64GB 的模型优化与交付。训练主机为 **4×RTX 4090**。

本轮只生成本目录内的设计资料；没有使用 git，没有修改业务实现、历史设计或外部项目，没有发起训练、采集或真机动作。线上核查使用只读 HTTP 和静态前端资源，未进行浏览器渲染级交互验收。

## 设计结论

1. **共用一套编排和资产生命周期，保留不同机器人接口。** 不用统一 DOF、固定相机数或某个 BHL 模板冒充通用支持。
2. **数据是可验证的 episode 与不可变版本。** 文件树只是入口；原始尝试、失败、时间戳、动作语义、筛选过程、训练划分都必须可查。
3. **RLinf 模型按能力矩阵纳管。** 已注册、能加载、能 SFT、能 RL、能评估、能在 Orin 运行，分别有证据，不能用一个“支持”开关代替。
4. **恢复评估和 sim2real 设计范围。** G1 EDU 当前仅仿真；SO101/BHL 的真实交付依据各自接口与现场验证，平台不进入实时控制回路。
5. **量化是模型的派生产物与独立评估流程。** 先有目标设备基线，再比较 FP16、INT8 或经验证的分模块方案；不承诺所有 VLA 都能在 Orin 上实时运行。
