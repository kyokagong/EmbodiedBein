## 删除功能

- 模型、训练、评估的列表和详情页新增删除入口，先展示关联文件和引用阻断项，再确认删除。
- API：`DELETE /api/v1/models/{id}`、`/weights/{id}`、`/train/{id}`、`/evals/jobs/{id}`；各自提供 `GET .../deletion-preview`。
- 训练/评估只允许终态对象；检查全部 Run、产物、模型、报告、管线、数据集、交付包、分享和有效血缘引用。存在消费引用时返回冲突，不自动删除下游模型。
- 文件清理由 ebd 完成，包括受管 Run 目录、对应模型目录和 TSDB。拒绝目录越界、祖先符号链接，以及仍活动或挂载清理路径的任务容器；仅移除已停止的对应任务容器。
- 删除前提交持久化清理记录。新提交和模型登记检查删除记录；失败可重试同一请求，重复完成请求幂等。审计保存原记录快照，血缘保留。
- 已删除外部模型不被启动扫描重新导入；删除的训练模型不被 RoboTwin 启动补登记重新创建。

1. 对照设计核对 Python/Rust 职责、发布对象不可变、外部源只读、血缘及 tombstone 保留。
2. 核对训练业务投影与真实 Job 状态、全部执行尝试、模型检查点、共享路径、恢复及评估引用。
3. 核对活动容器、TSDB 收集并发、数据库与文件清理的事务边界、失败重试、重复删除和平台 Agent 禁止删除。
4. 补查重启自动导入/补登记，防止删除对象重新出现；实际清理后逐项检查记录、文件、审计和保留模型。
