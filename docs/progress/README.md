判定约定：

- **完成**：对照该里程碑验收项，主路径已可运行（允许大镜像/真机仍用占位）。
- **可用骨架**：领域逻辑或 API 已有最小实现，端到端或缺关键环节，或 UI 仅为 JSON 回显。
- **占位**：有路由/模块/空镜像，但不能完成设计描述的工作。
- **未做**：设计要求的能力尚不存在。
