# 05 · 多轮反思与待确认

写完 00–04 和原型后，按五轮把文档当「别人的设计」重读。下面是改过的结论，不是过程流水账。

## 第 1 轮 · 对照你的原文逐条

| 你的原话 | 本版落点 | 是否缺口 |
|---|---|---|
| 实验改成训练，用来查看训练任务 | `/train` 列表即任务；实验表废弃 | 无 |
| 本体：注册、展示；代码接入；指定路径；解析 3D | 路径登记 + 扫描 + 现有 3D | USD 预览能力弱于 URDF，需在实现时降级为空态而不是假画布 |
| 数据：从指定处下载到指定目录；查看内容 | source/dest + 文件树；episode 能播则播 | 「指定处」若含需登录的网盘/内网盘，本版只写了 hf / http / path，见待确认 |
| 环境：Isaac Lab；镜像管理 | 独立导航；镜像实探 + pull | 无 |
| 训练：适配 RLinf；填表；历史/当前；日志指标结果 | 模板+常用字段+overrides；详情三块 | 无 |
| 模型：生成的 + 原始的；血缘 | base / trained + 三边 | 无 |
| 其它暂时不要 | 评估部署 Agent Showcase 任务 排行榜退出导航 | 现行代码仍在，只是设计范围外 |
| 元数据管理；磁盘存储；训练挂载目录 | 02 章 | 无 |

**这一轮补上的：** 下载/pull/扫描不能混进训练列表（否则「查看训练任务」又脏了）。

## 第 2 轮 · 词与边界

最容易做回去的错：把「环境」又做成 `ee_*` 本体环境。

已钉死：

- 环境 = Isaac Lab + Docker 镜像
- 本体环境 YAML 不是一等实体
- 任务 `tsk_*` 不是导航项
- 训练任务 ≠ 领域「任务」

**这一轮补上的：** RLinf 自己的 `env/isaaclab_*.yaml` 必须在训练表单里选，但不能因此再做一个叫「任务」的一级模块。它是环境扫描缓存 + 表单下拉。

## 第 3 轮 · 运行时会炸的事

1. **默认挂「当前路径」而不做 worktree**  
   你在 BHL 里改代码时，正在跑的训练会读到半成品。现行设计用 commit 冻结就是为了这个。  
   **本版决定：** 默认仍挂登记路径（符合「放在指定路径就行」）；在训练详情展示「路径此刻的 mtime/git SHA（若是 git）」作警告。冻结 worktree 列为后续，不挡本版。

2. **RLinf 默认把日志写回仓内**  
   必须在 Adapter 里强制 `log_path=/workspace/output`。这不是产品功能，是正确性。已写入 02/04。

3. **镜像 tag 漂**  
   提交时记 digest。环境页要能看 digest。

4. **4 卡与 Ray placement**  
   表单 GPU 数必须生成合法 `cluster.component_placement`，不能只改 `resources.gpus` 而 Hydra 仍写 `actor,env,rollout: 0`。已写入训练表单。

5. **44GB 数据详情**  
   文件树必须分页/惰性展开，禁止一次把 18974 文件 JSON 拉到浏览器。

## 第 4 轮 · 内部是否自相矛盾

| 可能的矛盾 | 裁决 |
|---|---|
| 「Isaac Lab 是环境」vs「训练镜像是 RLinf」 | 环境页默认训练镜像可以是 `eb/rlinf:*`（内含 Isaac Lab）。Isaac Lab 是仿真栈名称，不是必须选另一张纯 Isaac 镜像。 |
| 「不做 CAS」vs「ebd 还在」 | ebd 继续管容器和日志；不再把产物复制进内容寻址树作为主路径。 |
| 「不做评估」vs「训练详情有指标」 | 指标是训练曲线（reward/loss），不是 EvalSuite。 |
| 「模型血缘」vs「不强制 ModelCard」 | 血缘是 path + train_id + parent_id；不是完整模型卡。 |
| 现行短训主路径是 Isaac RSL-RL | 本版 UI 关掉它。实现可暂留 adapter，避免和「主要适配 RLinf」打架。 |

## 第 5 轮 · 原型与文档是否还缺页

已用原型补上、文档原先写得太短的：

- 训练列表空态 / running / failed 三种
- 表单预览（overrides + 挂载）
- 环境页「缺失镜像」与训练提交失败的跳转关系
- 本体接入失败（路径不在允许前缀）
- 模型血缘一条链：基座 → 训练 → 新模型

主导航不含设置；设置在侧栏底部（路径前缀 / RLinf 仓 / 默认镜像）。

仍故意没有的页：评估、部署、Agent、漏斗、队列独立页、任务实体 CRUD。
