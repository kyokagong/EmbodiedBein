# 官方 RPO-Flat / RLinf 接入与运行验收

本次接入使用 RoboLab `6b1c3d9988497c8961dcba77892de32edc1770e1`，目标是官方完整速度、横向运动、heading/转向指令，继续通过平台 API → Job/Run → ebd → RLinf 执行。没有修改外部仓，没有提交代码。实现对照现有训练、评估、环境目录和 RPO 设计；不修改已发布 WBC/AMP 接口或评估套件。

## 冻结的验收要求

- 新接口 `ee_rpo_v2_flat_23dof_v1`，训练模板 `rpo_v2_flat_ppo`，独立评估模板 `rpo_v2_flat_eval`。
- 官方 actor 780、critic 1390、23 维原生关节顺序，50 Hz；沿用环境、奖励、启动/运行随机化和噪声。
- 速度范围 vx `[-0.6, 1.0]`、vy `[-0.5, 0.5]`、yaw `[-1.57, 1.57]`；heading `[-π, π]`，heading 比例 1.0，20% 站立，每 10 秒重采样。地形 70% 平地、30% 轻微粗糙地面。
- 冒烟后至少 500 轮 PPO 更新。标准评估固定种子 50000–50099，100 个独立启动随机化案例，每例 20 秒 / 1000 个控制步。
- 单例 pass：完整运行 1000 步，无跌倒、非有限状态或物理硬越限，平移速度向量 RMSE ≤0.20 m/s、yaw 角速度 RMSE ≤0.30 rad/s。标准评估必须完成全部 100 例且至少 80 例通过。基础设施失败保留在计划分母，不计成功。

## 多轮反思与核查

1. **任务范围。** 舍弃仅站立加固定 0.3 m/s 直行的验收方案，采用官方完整指令采样。速度误差使用官方奖励的 yaw 对齐 XY 坐标，yaw 角速度使用 world Z。每一步比较物理推进前的指令与推进后的实际速度，避免重采样边界错误。
2. **环境接口。** 官方 BaseEnv 在 step 内自动重置；桥接层延后重置，让 RLinf 获得真实终止观测，再重置结束的环境。部分重置保留其他环境的观测历史。动作历史保存原始策略动作，物理动作仍按官方范围裁剪、缩放和默认姿态偏移。
3. **优化器与策略。** 沿用 512/256/128 ELU、可学习 Gaussian std、经验归一化、24 步 rollout、5 个 epoch、4 个 minibatch、clip 0.2、entropy 0.005、gamma 0.99、lambda 0.95、exact Gaussian KL 自适应学习率。专用 RLinf actor 使用官方 clipped MSE value loss，避免通用 Huber loss 改变基线。归一化在每轮 PPO 后更新，rollout 内固定，保留旧策略 log-prob 一致性；官方 RSL 每步更新，因此两者不保证训练轨迹完全相同。
4. **血缘与恢复。** 受管资产与 RLinf 源码冻结，任务容器只读挂载。评估计划分别记录训练实际使用的镜像和预览时冻结的评估镜像摘要，不能随当前 tag 漂移；独立评估可修复导出问题而不改已发布模型。checkpoint 包含 actor、critic、归一化统计、优化器、学习率、RNG；恢复模式明确为 trainer_state，不宣称恢复仿真状态或 rollout。模型发布后不可原地修改。
5. **证据与失败。** ONNX 含归一化，11 个 golden 输入包括边界值，与 PyTorch 输出比对；GPU 冒烟 v3 的最大误差实测 2.48e-5，低于 1e-4 上限。逐例初始物理参数和 gzip 轨迹带 hash；收集器重算成功率，检查计划、Run、策略与案例绑定。执行成功与评估合格分别记录。
6. **真实运行排障。** 实测发现 CUDA 关节索引不能直接索引 NumPy 硬限位；已先搬到 CPU。Isaac shutdown 可直接终止进程；先持久化评估 receipt。连续独立环境评估发现 `RayCaster.meshes` 类缓存保留前一地形和 Warp 对象循环；每个新 stage 前清理缓存，防止配置递归与旧地形复用，未绕过官方配置校验。
7. **独立复核。** 对运行镜像及实际 RLinf 调用链做只读复核；CPU 检查确认 logprob 一致、actor/std/critic 梯度有限，超时 bootstrap 和 GAE 一致。两组归一化的 `_mean/_std/_var/count` 共八个持久化 buffer 均经 FSDP state_dict → patch_syncer → HF rollout 同步，count 保留 int64；每轮同步一次。资格判定额外检查源 checkpoint 至少 500 轮，499/500 边界检查通过；较早 checkpoint 的标准评估仍可用于诊断，但不能资格 pass。
8. **评估运行预算。** 三种子冒烟的实际文件时间戳显示控制步约 0.076–0.091 秒，独立环境创建约 40 秒/例。100 例均跑满时预计约 3–4 小时；独立评估 Job 上限设为 6 小时，完整案例数、判据和随机化不变。
9. **训练后数值边界。** 第 500 轮模型的极端输入产生约 320.9 的未裁剪动作，PyTorch/ONNX 相差 0.000153；固定绝对误差 0.0001 误报导出失败。v2 改为 atol 0.0001 + rtol 0.00001，并保留裁剪动作误差检查。独立复核补查实际 batch=1，裁剪动作误差实测 0.000107、乘官方 0.25 后关节目标误差仅 0.0000267 rad。v3 同时保存 batch=1 与 batch=11 的 golden 证据，检查 raw 相对/绝对误差与关节目标误差 ≤0.0001 rad；v1/v2 已有凭据仍按原规则核验。运动 RMSE、跌倒、硬越限、100 例和 80 例通过的要求不变。
10. **报告状态对照设计。** 标准评估只要有基础设施失败，资格标记为 incomplete；100 例完整执行但成功不足 80 时为 fail。用行为检查覆盖这一分支，避免把模型失败与评估未完成混为一谈。
11. **硬限值来源。** 核对近期失败轨迹：踝关节滚转速度约 8.1–9.6 rad/s，超过官方 `roboparty.py` 的 `velocity_limit_sim=8.0`。该字段是 PhysX 仿真求解器速度约束，不能与仅用于执行器模型的 `velocity_limit` 混淆；求解器可能瞬时超出后制动，因此独立检查保留 0.001 容差，不把仿真成功推进当成没有越限。
12. **真实策略效果排障。** 1000 轮前 14 例实测 5756 步，ONNX 原始动作绝对值最大 4.13168；5616 个可重建的无噪历史观测经真实 checkpoint 归一化后绝对值最大 4.409、没有超过 5，未见动作或归一化范围发散。五个跑满时域案例中，yaw 指令平均值约 0.414/0.527/1.046/-0.699/-0.621，响应约 0.042/0.044/0.080/0.0019/-0.0165，转向跟踪确实很弱。500 轮评估 56 个跌倒帧的官方接触 terminated 均为 false，说明独立高度/倾角验收会早于训练接触终止触发；不据此把验收失败改成通过。完整训练逐步观测及逐项奖励尚未留存，无法凭总 reward 锁定学习根因。
13. **动作与指标语义。** 官方 RSL wrapper 在 env.step 前裁剪至 ±100，而 RLinf 桥保留原始动作历史；已测 500 轮全部 803022 个动作元素最大绝对值 5.35068，1000 轮前 14 例最大 4.13168，未触发该边界，不能据此认定学习失败根因，也不能宣称两套调用链逐位一致。RLinf `env/success_once` 实际表示轨迹内出现过正奖励，非完整任务成功；训练页已增加 Flat 专用说明，以独立 100 例判据作为合格依据。页面改动通过 vue-tsc 及训练页路由/指标行为检查（1 passed，8 个无关测试按名称跳过）。
14. **归一化节奏复核。** 实际 RSL 镜像在首次 act 前同样没有更新统计；首个输入使用 count 0、均值 0、std 1，除以 1.01。随后 RSL 对 env.step 返回的 O1…O24 逐步更新，当前 RLinf 在轮末合并采样输入 O0…O23，rollout/SGD 使用采样时缓存的归一化输入。CPU 复核证明相同观测集合逐步与批量合并的 mean/var/std 差 ≤3.58e-7，缓存输入重算 logprob/value 误差为 0；HF 的 `.eval()` 下直接 update 不生效。严格复现 RSL 需要另行处理 post-step 集合、terminal-only 估值及轮间重复观测；不能把未验证的归一化猜测直接当成学习失败根因。
15. **1500 轮早期硬限复核。** 前 16 例实际执行，0 通过、4 跌倒、10 硬限、2 满时域跟踪失败，0 基础设施/NaN；全部初始关节状态合法，前 14 个种子的完整 initial JSON 与 1000 轮完全一致。同前 14 例的动作最大绝对值由 4.13168 增至 5.43966，p99 由 1.56580 增至 2.51880，但早停造成测量步数不同，不能外推全套分布。越限仍集中于踝 pitch/roll：例如 seed 50006 第 2 步 roll 速度 8.06653 rad/s，seed 50013 第 8 步 pitch 位置 -0.615239 rad；两者初始状态均合法。seed 50012 位置 +0.601038 rad 只超出既定容差约 3.78e-5 rad，仍按冻结判据失败。未发现新的导出或仿真基础设施错误；不能把模型问题改标为基础设施失败。
16. **3000 轮最终结果与判据。** 标准 100 例全部有效、0 基础设施失败，19 例通过、58 例硬越限、23 例跑满时域但平移速度向量误差超标；这 23 例的 yaw 误差均满足 0.30 rad/s，全部案例 0 跌倒、0 NaN。累计训练存活时间提升及视频中的稳定动作没有替代硬限位与速度验收。没有修改判据来增加成功数；按用户要求结束本轮，保留完整配置、checkpoint、录像和证据供下一步评估。
