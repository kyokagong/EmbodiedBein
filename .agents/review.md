# 本次整理的复核记录

日期：2026-09-24。范围：仓库开发工具、接入/排障/开发技能和根目录操作入口；不修改产品实现或设计真源，不提交 Git。以下是文档整理的检查记录，不是平台运行验收。

## 第一轮：设计与当前实现对照

对照 `docs/design/01–06`、环境目录设计、当前路由、Makefile、Dockerfile、adapter、调度、产物收集与测试入口，并做无新技能的只读场景基线演练。

发现并修正：旧 AGENTS 的“仅 BHL 骨架”“任务镜像均为占位”“全部路由集中”“无 GPU 默认四卡”“血缘未接”“只加 adapter 即可接新栈”不符合当前代码。保留原硬约束及可配置存储根，增加技能入口和实际能力证据口径。

## 第二轮：四类接入的端到端遗漏

使用新接入技能复测非 BHL 本体、外部只读数据/模型、新 RLinf 算法，并加入任意 HF URL、HTTP 数据包、修改已发布接口三个边界场景。

补充/修正：

- 本体接口、Task、EnvironmentProfile、模板/Suite 是不同对象，不能只做页面或 YAML。
- 普通本地 validate 默认 LeRobot v3；HTTP 下载当前拒绝，HF revision/来源受限。
- 登记外部目录不自动冻结；模型下载不代表能被 loader 消费；评估数据不可混入训练。
- checkpoint 完整性、恢复状态、collector 分支、独立评估与血缘都纳入接入出口。
- `RenderedJob` 不承载 CPU/主存字段，预算从 `JobSpec.resources` 经 orchestrator 传递。

## 第三轮：失败路径与操作真实性

复测 queued、成功无模型、沙箱拒绝 Docker socket、默认端口无响应场景；逐项核对工具源码。

补充/修正：健康检查必须查看嵌套 `ebd.ok/error`；Doctor 要检查错误详情；`ebctl ps` 的回退/退出码不足以判健康；HTTP 命令有超时，沙箱不可访问不能推断主机没 GPU。纳入主存准入、部分 checkpoint、取消、管线恢复、日志回退、前端旧构建和模型资格失败等路径。

## 第四轮：开发交接与可维护性

检查已有工作区改动的保护、迁移/旧数据、容器化验证、ToolBus 禁令、前端检查和文档入口。复用已有 Makefile/API/ebctl，不新增重复 CLI 或框架；三个技能按场景加载，四类接入细节分参考文件。

复测补充：`make migrate` 不重建独立 migrate 镜像；`0001_init` 使用当前 metadata，需同时验证空库和旧库升级；只读挂载的 Ruff 使用 `--no-cache`；工具矩阵快照不能代替权限行为测试。
