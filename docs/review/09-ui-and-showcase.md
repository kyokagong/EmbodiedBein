## 2. Showcase 只读分享页专项审查 (`Showcase.vue`)

设计在 09.1 与 09.4 明确将 Showcase 定位为 **面向同事与观察者的核心成果展示窗口（P0 级）**。

```
设计高保真规格 (09.4):
```

## 3. 设置中心专项审查 (`Settings.vue`)

设计在 11.5 给出了设置中心的五大子页面规格：

1. **配额与水位 (`/settings/quotas`)**：磁盘配额水位条 (80% 告警 / 90% 阻断)、CAS 清理策略、GPU 周算力硬顶。
2. **镜像能力矩阵 (`/settings/images`)**：展示 4 大镜像的 Digest、支持的 JobKind 与 Model Family。
3. **扫描设置 (`/settings/scanner`)**：扫描根目录、扫描超时阈值、排除规则（如 `.git`, `__pycache__`）。
4. **通知与 Webhook (`/settings/notifications`)**：任务完成 / 门禁失败的 Webhook 推送地址。
5. **凭证与只读环境 (`/settings/secrets`)**：只读展示端口、时区 (`Asia/Shanghai`) 与 Redis 6380 状态。

### 现状：
- `Settings.vue` 目前仅有 14 行，仅显示 `版本 0.1.0 · eb/v1`，五大设置面板**完全未落地**。

## 4. 全局设计系统与交互一致性审查

1. **暗黑设计系统规范**：
   - 现存组件 (`EbKpi`, `EbTable`, `Chart`, `LogPane`) 风格较朴素，尚未完全应用 `docs/design/assets/eb/eb.css` 中定义的精致暗黑调色板、圆角与渐变高亮。
2. **全站三大不变量交互缺失**：
   - **血缘入口无处不在**：当前仅部分页面有血缘跳转，未做到任意实体一键探查上游来源。
   - **图表点下钻**：ECharts 图表上的散点无法直接点击跳转至生成它的 Run 或 Episode。
   - **通用对比抽屉**：列表页缺少通用的「勾选 2~4 项后底部弹出悬浮对比栏」的全局交互组件。
3. **全局 ⌘K 命令面板**：
   - 尚未集成全局快速跳转、快捷提交任务与快速唤醒 Agent 的命令面板。
